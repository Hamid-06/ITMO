## 📂 Структура репозитория

Все исходные коды проектов находятся в директории `Programming/`:

* 🔹 **Lab0** — Знакомство со средой, базовый синтаксис.
* 🔹 **Lab2** — Объектно-ориентированное программирование, наследование и полиморфизм на Java.
* 🔹 **Lab3-4** — Исключения, коллекции, работа со строками и кастомная логика.
* 🔹 **Lab5** — Управление коллекцией, работа с файлами (XML-хранилище) и обработка данных.
* 🔹 **Lab6** — Клиент-серверное приложение (UDP), сетевое программирование, сериализация объектов и Java Stream API.
* 🔹 **[Lab7](Programming/Lab7)** — Многопоточное клиент-серверное приложение (UDP), PostgreSQL, регистрация и авторизация пользователей, разграничение прав на маршруты.
